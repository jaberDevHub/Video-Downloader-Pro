# Video Downloader Pro - Stream & Media Saver (Chrome Extension)

A lightweight, 100% unlocked, privacy-focused media and video downloader for Chrome, Brave, and Edge (Manifest V3).

---


### Features

- **Universal Media Detection:** Detects `.mp4`, `.webm`, `.m3u8` (HLS), `.mpd` (DASH), `.mkv`, `.mov`, and audio streams (`.mp3`, `.m4a`, `.aac`, `.flac`).
- **Real-Time Player Interception:** Catches dynamically loaded video streams on SPAs (YouTube, Twitter/X, TikTok, Instagram, streaming sites) as soon as they play.
- **HLS Multi-Quality Parser:** Parses `#EXT-X-STREAM-INF` playlists to provide separate resolution options (1080p FHD, 720p HD, 480p, 360p).
- **Anti-Hotlinking Engine:** Uses `declarativeNetRequest` to dynamically inject required `Referer` and `Origin` headers so CDN-protected streams don't throw 403 Forbidden errors.
- **Zero Paywalls:** No daily download caps, no locked 1080p downloads, no cloud tracking, no accounts needed.
- **Avant-Garde Dark Mode UI:** Glassmorphism interface with instant search, quality filtering, live thumbnail previews, and in-popup video player.

### How to Install into Your Browser

1. Open your browser and go to:
   ```text
   chrome://extensions/
   ```
   *(For Brave: `brave://extensions/`, for Edge: `edge://extensions/`)*
2. In the top-right corner, turn on **Developer mode**.
3. Click the **Load unpacked** button in the top-left corner.
4. Select the folder:
   ```text
   \Video-Downloader-Pro

   ```
5. Done! Pin **Video Downloader Pro** to your toolbar and visit any site with videos.
